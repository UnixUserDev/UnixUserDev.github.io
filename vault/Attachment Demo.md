# Attachment Demo

A random photo, embedded. Because this **note embeds it**, Obsidian links the attachment — so it
shows up as its own node in the graph view (your `Show attachments` toggle is already on).


> [!tip] Try this
> `Ctrl+G` → find the `Random Photo.jpg` node hanging off this note. Then unlink it (delete the
> `![[...]]` line) and watch the node vanish. Attachments aren't in the graph by *existing* — only by
> being **linked**.
