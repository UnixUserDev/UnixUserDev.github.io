Screenshot preference: auto-copy to clipboard is wanted, auto-save to disk is not. Flameshot is configured with fl.saveAfterCopy=false and the Print hotkey runs "flameshot gui -c -s" (press Print, drag, release = image already in clipboard, no toolbar, no file written). Ctrl+Print opens the full toolbar for annotating; Shift+Print repeats the last region. Files are only written when explicitly saved.
