Agent skill packs that teach coding agents Roblox/Luau, for building games. Shortlist found 2026-10-22:

• MSayib/roblox-dev-skill (54★) — best quality: SKILL.md router + 14 reference guides (Luau, client-server, security, DataStores, UI, performance). Verified against Luau 0.743 / Studio 0.744, examples type-checked under --!strict and run in a real place, has CI. Installs to Claude Code, Codex, Cursor, Copilot, Gemini.
• nonlooped/roblox-suite (23★) — "API guidance for AI agents writing Roblox Luau", aimed at deprecated APIs (Humanoid:LoadAnimation, blind SetAsync). Each skill links official docs + review date. `npx skills add nonlooped/roblox-suite`.
• luumenlabs/luau-skills (13★) — literal name match: luau-core, luau-types, luau-performance, roblox-networking, roblox-data, roblox-oauth. `npx skills add luumenlabs/luau-skills`. Quiet since May.
• TabooHarmony/roblox-brain (121★) — 29 skills, Luau/architecture/security Core set of 10 is the centrepiece.
• m4bwav/roblox-agent — use if the goal is checking Luau WITHOUT Studio: rbx_check runs rojo build, selene, StyLua, luau-lsp.
• Bigger umbrella: gamedev-skills/awesome-gamedev-agent-skills (~2.9k★), 74 skills over 10 engines incl. Roblox, with a router.
• Full agent apps (not skills): S4US/Roqer, paralov/app-bloxbot-ai, Roblox/roblox-studio-agent-plugin (official, Claude/ChatGPT/Codex).

Avoid: shivamthe-coder/roblox-luau-atelier — ranks high for "Luau agent skill" but is SEO bait: fake SVG download button, "SEO-Friendly Philosophy" section, README self-renames to "RoBlocks Studio Toolkit".

Verdict: MSayib/roblox-dev-skill first, nonlooped/roblox-suite second. Both are plain Markdown, nothing runs until their installer is invoked.
